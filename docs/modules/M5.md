# M5 — AI service skeleton

## Is module me kya banaya
AI service (`apps/ai-service`) ka pura dhaancha: ek endpoint `POST /v1/process`, service-token auth, LLM provider layer (Anthropic + OpenAI, fallback, circuit breaker, cost tracking), versioned prompts, Langfuse tracing, aur media ke liye SSRF-safe fetcher. Gateway me `ai-client` module bana jo is endpoint ko call karta hai, aur `InboundRouter` ab consented user ke har normal message ko AI service ko bhejta hai. Abhi AI sirf text ka intent pehchanta hai aur fixed template se jawab deta hai; prescription padhna M7 me aayega. LangGraph, emergency classifier, Presidio aur extraction is module me nahi hain.

## Kyun zaroori tha
Aage ke saare features (prescription, lab report, generic finder) isi service par chalenge. Agar pehle se contract, auth, retry/fallback, cost aur tracing na ho, to har feature me yehi kaam dohrana padega. Aur LLM provider kabhi bhi down ya slow ho sakta hai: bot ko tab bhi user ko saaf jawab dena hai, chup nahi rehna.

## Kaise kaam karta hai
```
WhatsApp ─► webhook ─► inbound queue ─► InboundRouter (consent ✓)
                                            │
                                      AiProcessor (gateway)
        media: ack "padh raha hoon" ─► S3 me store ─► presigned URL (5 min)
        text : DB me rakha REDACTED text
                                            │  POST /v1/process  (X-Service-Token)
                                            ▼
                                  AI service (stateless)
                  Pipeline ─► LLMRouter ─► primary provider ──(timeout/429/5xx)──► fallback provider
                       │                        │ per-provider circuit breaker
                       │                        └ structured JSON, 1 repair retry, cost = tokens x pricing.yaml
                       └ Langfuse trace (text redacted, images kabhi nahi)
                                            │
                          reply {text, buttons, meta{model, cost, latency}}
                                            ▼
                     outbound queue ─► WhatsApp (ek hi baar; fail hua to ek hi error message)
```
Gateway aur AI service alag hain: gateway user ka state rakhta hai, AI service stateless hai aur kabhi WhatsApp message nahi bhejti.

Contract-first: Pydantic schemas ─► `make contracts` ─► `packages/contracts/openapi/ai-service.json` ─► gateway ke TypeScript types (`apps/gateway/src/ai-client/generated/`). CI dobara generate karke `git diff --exit-code` chalata hai, to schema badla aur types nahi badle to CI fail.

## Important technical decisions
- **Fallback sirf infra errors par** (timeout, 429, 5xx, connection). 400/auth/schema error dono providers par fail hota, to fallback se bas paisa double hota. Trade-off: kuch genuine request fallback par nahi jaati, par galat retries bhi nahi hote.
- **Circuit breaker per provider** (5 failures, 60 s cooldown, half-open probe): jab primary mara hua ho, har request uska timeout na bhugte.
- **Structured output + 1 repair retry**, phir `LLMSchemaError`. Free text kabhi nahi, kyunki composer ko sirf structured data bolna hai (§2.5).
- **Model ids env se** (`VISION/TEXT/CHEAP_MODEL` + `FALLBACK_*`). Hard-code nahi, kyunki models roz badalte hain.
- **AI ko redacted text**: webhook ne phone/Aadhaar-like/PIN pehle hi hata diye; raw text kahin nahi.
- **Presigned URL + SSRF guard**: AI service sirf allowlisted host se, bina redirect, mime aur size limit ke saath file khinchti hai.
- **Fake mode (`LLM_MODE=fake`)**: tests aur CI ko API key nahi chahiye. Production me refuse hota hai.
- **Gateway retry policy**: sirf connection error aur 5xx (504 nahi, kyunki AI service apna poora time use kar chuki). Error message ka reply index fixed (99), to user ko ek hi error message milta hai chahe job kitni baar retry ho.
- **Placeholder prices**: `pricing.yaml` ke daam abhi asli nahi hain; cost number tab tak bharosemand nahi.

## Production-ready points
- Service token `hmac.compare_digest` se check hota hai; 64 KB body limit; error body me provider ka message kabhi nahi jaata.
- Logs me sirf numbers aur ids (latency, cost, model, trace id), message ya reply ka text kabhi nahi. Langfuse me `mask=redact_value`, images bhejte hi nahi.
- Tests: ai-service 309 (router, breaker, providers via `httpx2.MockTransport`, pricing, prompts, tracing, fetcher, endpoint, contract), gateway 691 unit (AiClient with nock: timeout, 5xx retry, no retry on 4xx/504; AiProcessor flows; contract test), integration: AI branch reply once, AI down -> ek error message. Production Docker image fake mode me boot aur `/v1/process` jawab verify kiya.

## Interview me kaise bolna hai
"Maine AI ko alag stateless FastAPI service banaya jo ek contract par chalti hai: Pydantic se OpenAPI banta hai aur usse gateway ke TypeScript types generate hote hain, CI me drift check ke saath. LLM calls ek router se jaati hain: primary Claude, fallback GPT-4o, sirf timeout/429/5xx par fallback, har provider ka circuit breaker, structured JSON ek repair retry ke saath, aur har call ka cost track hota hai. Gateway sirf redacted text ya presigned URL bhejta hai, aur AI fail ho to user ko ek hi error message milta hai. Tests fake LLM se chalte hain, to CI me koi API key nahi lagti."

## Possible interview questions
1. **Anthropic down ho jaye to?** Router timeout/5xx dekhkar fallback provider par jaata hai; baar baar fail ho to breaker us provider ko 60 s ke liye skip karta hai. Dono down hon to 503 aur user ko "dobara try karein" message.
2. **LLM galat JSON de to?** Ek repair retry (error batakar dobara poochna), phir bhi galat to `LLMSchemaError`; user ko galat data nahi jaata.
3. **Cost control kaise?** Har attempt ka token usage aur `pricing.yaml` se cost, response `meta.cost_usd` me aur trace me. Daily budget guard M15 me.
4. **Prompt badalne par kya track hota hai?** Prompt file me version header (`intent_text_v1`), `meta.prompt_version` me wapas aata hai; badalna = version bump + eval (M14).
5. **Presigned URL se kya risk?** SSRF: isliye host allowlist, no redirect, no credentials in URL, mime/size limit, aur URL 5 minute me expire.
6. **Contract drift kaise rokte ho?** `make contracts` deterministic hai; CI regenerate karke `git diff --exit-code` chalata hai.
